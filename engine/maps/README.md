# Bundled maps

fheroes2's own maps in its `.fh2m` ("Resurrection") format, made by the fheroes2 community with its map editor and bundled in the [fheroes2 repository](https://github.com/ihhub/fheroes2/tree/master/maps) (GPL-2.0), taken at commit 47cbabf3e (2026-08-31). The tool scouts them alongside the maps in the game data folder. They still need Heroes of Might and Magic II graphics to render.
